# Jacob Sriraman

Source for [jacobsriraman.github.io](https://jacobsriraman.github.io/), a simple
personal website built with Jekyll and hosted on GitHub Pages.

## Edit the site

- **Introduction and optional personal details:** `_data/home.yml`
- **News:** `_data/news.yml`
- **Contact links and search description:** `_config.yml`

Start with [EDITING.md](EDITING.md) for writing prompts, examples, and local
preview instructions. Optional sections stay hidden until you fill them in.

## Design

One page, two navigation links, no JavaScript or external fonts. The page uses
`_layouts/personal.html` and `assets/css/personal.css`. Unused starter content
is excluded from the published site; old main navigation URLs redirect home.

Originally based on [Academic Pages](https://github.com/academicpages/academicpages.github.io).
The original template files remain available under the included MIT license.
